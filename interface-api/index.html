i V1 vs V2 — différences clés V1 Modèle du mémoire d'origine, gelé. Confiance C = S_stat · S_liq · S_coh. Le prix est servi tel quel, dans la devise du pool. V2 Neutralisation du peg stablecoin avant S_coh : price_usd = prix × peg(T). Nouveau sous-score S_peg qui signale un dépeg séparément, plus un flag de fragilité. Concrètement, V2 évite les fausses alertes de cohérence lors d'un dépeg stablecoin (ex. USDC, faillite SVB le 11/03/2023) tout en remontant l'événement via S_peg.
